MIDWAY R23 — актуальный клиент для PvE R23
SCUM 1.3.5.1.172191+172352, build 26280172. Полный клиент: 71 PAK.

Полностью закройте SCUM. Перезапустите лаунчер, проверьте обновления модов
и дождитесь завершения установки. Только после этого запускайте игру.
Клиент R17 и старые тестовые сборки не используйте для подключения к PvE R23.
Если лаунчер оставил старый набор, удалите моды его штатной кнопкой и установите
заново. Официальные файлы SCUM и сохранения вручную не удаляйте.

GitHub main и launcher-metadata теперь выдают один полный снимок R23.
Для ручной установки из репозитория нужен Git LFS: обычный Source code ZIP
может содержать текстовые указатели вместо PAK. Проверка: VERIFY_FILES.cmd.
Все папки с PAK из INSTALL_MANIFEST.json необходимы, включая R16/R17/R18 и
исторически названные TEST: эти названия не означают, что файл лишний.
Отклонённый MIDWAY_Aircraft_Map_Shop_R22_809_P.pak в набор не входит.

Реестр и сетевой конфиг этого клиента совпадают с PvE R23. Прежние сетевые
идентификаторы сохранены; две фабрики магазина добавлены в конец.
Серверная версия отдельная: не устанавливайте SERVER игрокам.
PvP пока остаётся на R17; этот выпуск согласован с PvE R23 и тестовым R23.

Состав R23: плавная остановка винтов MH6/Huey, повышение HP авиации,
проверки сетевой физики/опор, ввод карты при масштабировании, иконки магазина
и ранее подготовленные исправления R18–R21. Мир PvE загрузился без ошибок
загрузки. Нативная проверка потери HP, пилота у наблюдателя и пассажиров V-22
двумя игроками ещё не завершена; отсутствие всех крашей не заявляется.
