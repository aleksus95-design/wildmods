СОСТАВ
Рулетка R6H18: 4 места, до 3 ставок, произвольная сумма 1–10000 фишек,
немедленное списание, общий отсчёт, колесо, результат и баланс в панели.
40 фишек покупаются за 1 млн наличных одним стаком без распаковки.
Входит также актуальный комплект модов тестового клиента: камеры,
дартс, Deep, CCTV, транспорт, MOD+ и прочие сохранённые зависимости.
R77 исправляет привязку мишени; R78 закрывает старые рецепты WK за монеты;
R79 исправляет дорожки камеры Спартанца и параметры пассажиров Вертолёта2.

ГРАНИЦЫ ПРОВЕРКИ
Архивы проверены по CRC/SHA256. Реестр и конфиг клиента/сервера совпадают;
сетевые поля и RPC общих Blueprint проверены отдельно. TEST загрузился.
R6H18 прошла ограниченный сетевой тест выплат, отказа при нехватке фишек,
повторного открытия и переподключения. Крупные выплаты до 1 млн проверялись
в изолированной игре. Два реальных клиента в последнем прогоне не участвовали.
R77/R78/R79 требуют проверки соответствующих действий игроком. Причина
редких heartbeat-разрывов и блокировки водительского места ЗИЛа не устранена.
R41 оставлен только на сервере как ранее: он отключает репликацию компонента
меток отряда карты. Имя DIAGNOSTIC историческое; удалять его по имени нельзя.

КЛИЕНТ
Перед установкой полностью закрыть SCUM. Сохранить текущие моды вне
SCUM/Content/Paks, затем установить SCUM из Client_FULL в корень игры.
Не смешивать полный комплект с PRIVATE Q5/Q6/Q7 и другими версиями рулетки.
Проверить VERIFY_FILES.ps1. Официальные PAK/SIG не заменять.
При обычном сетевом обновлении локальные сохранения не удалять. До первого
запуска сохранить обе локальные папки SaveFiles и SaveGames отдельно.
Для отката несовместимой ветки использовать согласованную версию модов и
её сохранения; не загружать старую R12 с предметами новых классов фишек.

состава предназначен PATCH (21 новый PAK), FULL — запасной полный набор
управляемых MIDWAY-модов, не копия всех данных сервера.

использовать ZIP, затем проверить обратным скачиванием хеши PAK: веб-загрузка
отдельного PAK ранее портила бинарник преобразованием переводов строк.
Перед активацией повторно сверить BASELINE.json: PAK, пути, размеры и SHA256.
Если состав изменился, пересчитать план, не продолжать слепую замену.
Остановить сервер штатно, сохранить текущий мир, SaveFiles/SaveGames,
реестр выплат рулетки, настройки, действующие PAK и manifest лаунчера.
Развернуть PATCH по точным путям манифеста. Старые файлы для PATCH удалять
не нужно. NeDjin и другие отдельные серверные расширения сохранить.
FULL нельзя просто наложить поверх другого полного набора: сначала убрать
только прежние управляемые MIDWAY PAK по сохранённому списку вне Paks,
сохранив NeDjin и другие не входящие в манифест расширения.

После запуска проверить mount, завершение LoadMap, вход клиента, MOD+,
