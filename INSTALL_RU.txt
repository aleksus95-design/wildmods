MIDWAY / WILDMODS — SCUM 1.3.6.0, BUILD 26593778
Полный клиентский комплект: 100 PAK. Только для соответствующего обновления PvE/PvP.

ЧИСТАЯ ЗАМЕНА ПРЕЖНЕГО КОМПЛЕКТА
1. Полностью закройте SCUM.
2. ПЕРЕМЕСТИТЕ прежнюю папку SCUM/Content/Paks/~mods (или ~Mods) целиком
   в резервную папку ВНЕ SCUM/Content/Paks. Простого копирования для резерва мало:
   в игровом каталоге прежних модовых PAK остаться не должно.
3. Если модовые PAK лежат непосредственно в Content/Paks или в других его подпапках,
   перенесите эти старые модовые файлы туда же, за пределы Content/Paks.
   Не удаляйте и не перемещайте официальные игровые PAK и SIG SCUM.
4. В частности, нигде внутри Content/Paks не должен оставаться старый
   MIDWAY_Client_FULL_B25804202_R19_225_P.pak: в нём несовместимая основная карта.
   Не совмещайте этот полный выпуск с прежним набором или отдельными TEST PAK.
5. Скопируйте папку SCUM из архива в корень установленной игры SCUM.
   Должен получиться путь SCUM/Content/Paks/~mods/… с ровно 100 PAK из манифеста.
6. Для проверки распакованного комплекта запустите VERIFY_FILES.cmd.
   Требуется Python 3.11 или новее. Проверка установленной папки:
   python verify_files.py --paks-root "ПУТЬ К ИГРЕ/SCUM/Content/Paks"
7. Подключайтесь после объявления о завершённом обновлении соответствующего сервера.

Сохранения удалять не нужно. Реестр, список PAK и SHA-256: INSTALL_MANIFEST.json.
Проверка файлов подтверждает целостность комплекта, а не версию работающего сервера.
Архив не содержит официальных файлов игры и не обновляет сервер автоматически.
