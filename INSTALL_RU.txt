# MIDWAY R40 — клиент PvE / PvP

SCUM 1.3.5.2.172724+172352, build 26320533. Полный клиент: **83 PAK**.
Серверная версия отдельная: **81 PAK**. Клиент R40 используется с серверным R40.

Полностью закройте SCUM, перезапустите лаунчер, проверьте обновление модов и дождитесь окончания установки. При технических работах дождитесь запуска сервера. Не смешивайте R23 и R40. Старые 3 PAK исключены из манифеста; 68 файлов сохранены, 15 добавлены. Историческое TEST в имени оставшегося файла не означает, что его нужно удалить.

Изменения: качалка со штангой и уменьшенным расходом выносливости; интерьер и магазин RU/EN; исправления материалов декора и сундука; кормление коня фруктами/овощами; телега с колёсами; стрелка и часы миникарты; скины рюкзаков и роботов; собственные проекции ЗИЛа, Вертолёта №2 и стоящей лошади. В технологиях: сундук телеги за 25 коинов и подсумок лошади за 15.

Владелец подтвердил качалку, расход выносливости, текстуры роботов и проекции/размещение трёх машин. Файлы проверены по SHA-256; очистка сохраняет итоговые данные. Зависимости проверены, сетевые контракты 2525 общих Blueprint согласованы; реестр и сетевой конфиг двух версий совпадают. Интерфейс миникарты имеет отдельный клиентский вариант без сетевых полей/RPC.

Полная игровая проверка двух клиентов ещё не завершена. Вход чистой игры без модов остаётся в расследовании; этот выпуск не заявляет его исправленным. Покупки новых аксессуаров и сохранение кормления требуют проверки в игре. Автоматический шокер сундука не заявляется реализованным.

Для ручного получения файлов используйте Git LFS: Source code ZIP GitHub может содержать указатели вместо PAK. `python verify_files.py` проверяет репозиторий; `python verify_files.py --paks-root <путь_к_SCUM/Content/Paks>` проверяет установленный клиент. Серверные PAK, журналы, настройки и сохранения в этом репозитории отсутствуют.

Не заменяйте официальные PAK/SIG и Saved. При откате клиент и сервер должны вернуться к согласованной версии.
