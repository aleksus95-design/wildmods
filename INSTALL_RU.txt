MIDWAY M13 + Tank R95 — общий клиент для PvP и PvE
19.10.2026 · SCUM build 25804202 · 31 PAK

Установка через лаунчер:
1. Дождитесь объявления об окончании технических работ.
2. Закройте SCUM и перезапустите лаунчер.
3. Нажмите «УДАЛИТЬ МОДЫ», затем установите актуальные моды.
4. Подключайтесь к серверу с обновлённым комплектом.

Ручная установка:
1. Закройте SCUM. Сохраните прежние папки MIDWAY за пределами Content/Paks.
2. Уберите прежние пользовательские PAK, включая R84_326 и тестовый R95_614.
   Официальные файлы PAK/SIG игры не меняйте.
3. Скопируйте папки MIDWAY_Full, MIDWAY_MODPlus_TEST и MIDWAY_Skyline_Q38_TEST
   из этого комплекта в SCUM/Content/Paks/~mods.
   При скачивании через Git должны быть получены настоящие файлы Git LFS.
4. Запустите VERIFY_FILES.cmd с путём к SCUM/Content/Paks в кавычках.
   Без аргумента проверяется скачанная папка. Требуется Python 3.
   Проверка сообщает о лишних, отсутствующих, изменённых и дублирующихся PAK.
