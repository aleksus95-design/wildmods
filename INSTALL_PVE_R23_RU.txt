MIDWAY R23 — накопительное обновление PvE с R17
SCUM 1.3.5.1.172191+172352, build 26280172.

ДВА РАЗДЕЛЬНЫХ АРХИВА: CLIENT для игрока, SERVER для выделенного сервера.
Оба требуют уже установленного ПОЛНОГО R17 соответствующей роли.
Это обновление из 7 PAK, а не полный комплект для чистой установки.
После установки: CLIENT 71 обязательный PAK, SERVER 73 обязательных PAK.
Старые R16 и R17 нужны: они содержат базовые модели, звуки и исправления.

УСТАНОВКА
Полностью закрыть SCUM или остановить выделенный сервер.
Сохранить прежний MIDWAY_MapZoom_RU_R1_772_P.pak вне Content/Paks.
Скопировать вложенную папку SCUM в корень игры (сервер: /Server).
Разрешить замену только MIDWAY_MapZoom_RU_R1_772_P.pak в MIDWAY_R16.
Остальные шесть файлов добавляются; официальные PAK/SIG и Saved не изменять.
На тестовый клиент R21/R23 этот накопительный архив повторно не накладывать:
он уже содержит эти патчи в своих папках. Дубликатов одинаковых PAK быть не должно.
На PvE комплект уже установлен автоматически, повторная загрузка не нужна.
Все игроки PvE должны использовать клиентский R23 после перезапуска игры.

Этот отдельный выпуск опубликован по прямому разрешению владельца на PvE.
PvP и общий канал лаунчера остаются на R17. Для PvE обновить клиент этим
архивом или клиентской веткой release/pve-r23 с Git LFS.
Source code ZIP GitHub не заменяет архив CLIENT: там возможны указатели LFS.

СЕТЕВЫЕ ИДЕНТИФИКАТОРЫ
Прежние 13143 Primary IDs и 3047 factory IDs сохранены в порядке R17.
Две фабрики магазина добавлены в конец, прежние ID не сдвигаются.
Текущий AssetRegistry и WindowsGame.ini совпадают у обеих ролей.
R23_810 сам не добавляет ID; прежние RPC/реплицируемые поля сохранены.
В AnimBlueprint добавлены только временные нереплицируемые поля вращения.

ПРОВЕРКА И ОГРАНИЧЕНИЯ
PAK и архивы проверены по SHA-256. Лабораторные проверки UE пройдены.
На тестовом сервере мир R23 загрузился без ошибок загрузки.
Нативный игровой тест двух игроков ещё не подтверждён: потерю HP на земле,
выпадение пилота у наблюдателя и краши пассажиров V-22 нельзя считать
окончательно устранёнными. Сначала проверить свежие вертолёты на земле,
HP до/после минуты с пилотом, винты после выключения/выхода, затем полёт.
Полный иммунитет Спартанца к перегрузу, расширение кормления коня и звук
танка у других игроков ещё не закрыты этим выпуском.
