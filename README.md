# MIDWAY R40 RC1 — кандидат клиента PvE / PvP

Подготовлен локально. Канал лаунчера пока не переключён. Требуется согласованный серверный R40 и сетевой тест.

MIDWAY R40 RC1 — подготовленный комплект PvE / PvP, 31.10.2026
SCUM 1.3.5.2.172724+172352, build 26320533.

Это кандидат для согласованного тестирования. Основные серверы и общий лаунчер пока R23.
Клиент R40 нельзя выдавать всем игрокам раньше серверного R40. Клиентская и серверная версии раздельные.
CLIENT_READY: 83 PAK для игрока. SERVER_READY: 81 PAK для выделенного сервера.
20 полностью перекрытых PAK исключены с сохранением итоговых данных. Из серверного набора исключена тестовая повышенная частота Сильвера.
Старые пути оставшихся файлов сохранены: лаунчеру не нужно скачивать неизменённые PAK заново.

Что включено: исправления R24–R40 поверх действующего R23, качалка с рабочей штангой и медленным расходом выносливости, интерьер и магазин RU/EN, исправления сундука/декора, кормление коня, телега с колёсами, стрелка и часы миникарты, новые скины рюкзаков и роботов, проекции ЗИЛа/Вертолёта2/лошади, сундук телеги за 25 коинов и подсумок лошади за 15.
Это перечень изменений, а не утверждение о завершении всех игровых проверок. Автоматический шокер сундука не заявляется реализованным.

Подтверждено владельцем: качалка/штанга и расход выносливости, текстуры роботов, проекции и размещение трёх машин R40, прежняя загрузка/открытие сундука.
Проверены SHA-256, побайтовое сохранение после очистки, зависимости, серверные аудиособытия, сетевые контракты и совпадение реестра/config клиента и сервера.
12 526 штатных индексов ранее проверены точной сортировкой UE без сдвигов; совпадение metadata не заменяет сетевой тест.

До публикации нужны: тест R40 двумя клиентами, покупки/крепления аксессуаров, кормление/сохранение и перезапуск сервера. Разрыв входа чистого клиента PvE ещё расследуется.
Проекция лошади R40 получена из штатной модели в разрешённой закрытой лаборатории; в текущем кандидате она остаётся приватной. До публичного размещения необходимо решить происхождение/замену этого ресурса. RELEASE_GATE.json запрещает автоматическую публикацию сейчас.

Установка после разрешённого теста: полностью закрыть игру либо остановить сервер. Сохранить прежние моды вне Content/Paks. По DEPLOY_PLAN проверить ожидаемые SHA, переместить перечисленные старые PAK в резервную папку и установить файлы обновления. Не удалять неизвестные файлы и не смешивать комплекты. VERIFY_FILES.cmd или VERIFY_FILES.ps1 проверяет весь комплект и отсутствие дополнительных PAK.
Официальные PAK/SIG, Saved, БД мира и настройки PvE/PvP не заменяются.
Откат — остановить процесс и восстановить прежний комплект модов и соответствующий клиент. БД автоматически не откатывать.

Архив FULL используется для чистой установки; UPDATE — только поверх точного R23 соответствующей роли и по плану замен. Репозиторий содержит только клиент; серверные PAK, логи и пароли в GitHub не включены. GitHub Source code ZIP не заменяет полный архив: для PAK нужен Git LFS.
