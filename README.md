# MIDWAY — моды для лаунчера

Актуальный комплект M13 / Loot R1 / Skyline Q38 / Coins R6, SCUM build 25804202.
Один общий магазин для PvP и PvE. В «Экипировке» только три рюкзака по 50 монет; костюмы убраны из панели. Тепловизор 250, целеуказатель 500. Остальные цены и прежние исправления сохранены.

После обновления перезапустите лаунчер, удалите старые моды и установите актуальный комплект. Официальные файлы игры не удаляйте. В наборе ровно 31 PAK; лишние старые PAK могут конфликтовать.

[Полный архив, инструкция и контрольные суммы](https://github.com/aleksus95-design/scum-midway-client-test-r15/releases/tag/full-m13-loot-r1-q38-20261019).

Лаунчер читает main и согласованный launcher_mod_manifest.json из ветки launcher-metadata. Резервная копия предыдущего комплекта сохраняется отдельно перед развёртыванием.
