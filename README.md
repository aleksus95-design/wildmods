# MIDWAY / WildMods — SCUM 1.3.6

WildMods / MIDWAY для SCUM 1.3.6.0: полный клиентский комплект из **100 PAK**.

Сохранены 98 опубликованных PAK. Старый FULL R19 заменён на R20 без устаревшей основной карты; добавлен пакет совместимости 1703 с реестром новой версии игры. Миникарта расположена слева сверху, часы под ней. Сохранён состав модов действующего PvE/PvP; отдельные экспериментальные пакеты тестового сервера не добавлены.

Проверены структура и контрольные суммы всех PAK, эффективные ресурсы, зависимости и CRC/SHA полного архива. Статический аудит окончательного клиента/серверов: отсутствующих жёстких зависимостей и экспортов нет. Мир, MOD+ и подключение проверены на тестовом профиле; это не утверждение о проверке каждого игрового сценария на PvE/PvP.

**При ручной установке полностью переместите прежний модовый комплект за пределы `SCUM/Content/Paks`, затем установите этот FULL.** Особенно важно убрать `MIDWAY_Client_FULL_B25804202_R19_225_P.pak`. Старый и новый FULL одновременно оставлять нельзя. Официальные PAK/SIG и сохранения не трогать. Подробная инструкция и SHA-256 приложены.

Клиент используется с соответствующим обновлением PvE/PvP. Статус развёртывания серверов указывается отдельно; до завершения обновления канал лаунчера не переключается.
