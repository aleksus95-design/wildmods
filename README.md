# MIDWAY — моды для лаунчера

Комплект M13 + Tank R95 · SCUM build 25804202 · 31 PAK.
Общий клиентский комплект для серверов PvP и PvE.

R95 содержит исправления обработки замка танка и фонового расхода аккумулятора
при выключенном двигателе. Переключение камеры на Enter сохранено.
Проверки файлов и логики пройдены; установка замка и стоянка требуют проверки в игре.

После объявления об обновлении закройте SCUM, перезапустите лаунчер,
нажмите «УДАЛИТЬ МОДЫ» и установите актуальный комплект.
Официальные файлы игры удалять не нужно.

Полный файл MIDWAY_Tank_B25804202_R95_326_P.pak заменяет R84_326.
Старый R84 и отдельный тестовый патч MIDWAY_Tank_FIX_R95_614_P.pak
вместе с этим комплектом не устанавливайте.
Остальные PAK входят в комплект и сохраняют необходимые зависимости.

Инструкция: INSTALL_RU.txt. Точный состав: INSTALL_MANIFEST.json.
VERIFY_FILES.cmd проверяет скачанную папку; путь к SCUM/Content/Paks
можно передать первым аргументом для проверки установленной игры.
Проверка требует Python 3 и ничего не изменяет.

Лаунчер получает файлы из main и согласованный launcher_mod_manifest.json
из ветки launcher-metadata. Предыдущая версия сохранена для отката.
