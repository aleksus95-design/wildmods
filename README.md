# MIDWAY R16 — клиентский комплект

SCUM 1.3.5.0.172191, build 26271977. **64 PAK**, общий клиент PvE/PvP.

Закройте SCUM, перезапустите лаунчер и переустановите моды: удалите прежний
пользовательский комплект через лаунчер, затем установите текущий.
Официальные PAK/SIG игры сохраняются. После установки запустите игру заново.

Для ручной установки получите настоящие PAK через Git LFS (`git lfs pull`),
сохраните старые моды вне `Content/Paks` и скопируйте папку `MIDWAY_R16`
в `SCUM/Content/Paks/~mods`. GitHub Source code ZIP может содержать указатели LFS.
`VERIFY_FILES.cmd` проверяет папку репозитория, а с аргументом пути
`SCUM/Content/Paks` — установленный клиент. Требуется Python 3.

[Серверный комплект: отдельный архив из 66 PAK](https://github.com/aleksus95-design/wildmods/releases/tag/midway-r16-20261028).
Серверные PAK в клиентскую папку не устанавливать. Игрокам нужен этот клиент R16.

В комплект включены исправления совместимости SCUM 1.3.5, материалов транспорта,
дверей Skyline, стартового арбалета, вертолётов и радиомашинки.
Радиомашинка: F9 подключить/выйти, V сменить камеру; R16 скрывает корпус и заряд
только в собственном виде от первого лица.

Удалены 16 полностью перекрытых архивов; эффективные файлы сохранились побайтно.
Проверены реестр, сетевой конфиг и поля/RPC 2271 общих Blueprint клиента/сервера.
Серверный краш ЗИЛа и исправления Skyline/стартового арбалета проверены владельцем.
Камера R16 прошла 45 проверок UE и 17 сетевых проверок в лаборатории;
её проверка в SCUM отложена владельцем. Проверка PvE/PvP после рестарта ещё нужна.
Это не утверждение, что все игровые сценарии пака уже протестированы.

`INSTALL_MANIFEST.json` содержит точный состав, размеры и SHA-256.
Предыдущие ветки сохранены в тегах `backup/pre-r16-main-20261028`
и `backup/pre-r16-metadata-20261028`. Миры и настройки серверов не входят в раздачу.
