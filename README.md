# MIDWAY R46 — клиент PvE / PvP

SCUM 1.3.5.2.172724+172352, build 26320533. Полный клиент: **87 PAK**.

Исправлена отправка кормления лошади на сервер. На выделенном тестовом сервере
подтверждено: яблоко из рук расходуется, запас корма у лошади прибавляется.
Еду и корм изменяет сервер после проверки доступа, расстояния и состояния лошади.
Изменены только обработчики взаимодействия лошади и её контейнера; реестр,
классы, поля репликации и существующие сетевые идентификаторы сохранены.

Закройте SCUM и обновите моды через лаунчер. Серверные файлы загружены без
остановки: исправление на основном сервере начнёт работать после следующего
рестарта этого сервера. Клиент и сервер должны использовать R46.
Возьмите овощ или фрукт в руки, подойдите к неподвижной лошади с неполным
запасом корма и выберите «Покормить». Сообщение H46-C означает отправку запроса;
результат подтверждается следующим сообщением сервера и расходом еды.

R46 заменяет только MIDWAY_Horse_Feeding_R42_837_P.pak в клиентском комплекте.
Лаунчер уберёт прежний файл при синхронизации. Остальные 86 PAK сохранены,
включая подбор дрона R42, строительство R43 и короткие имена сундука R44:
```
#SpawnItem MW_Chest 1
#SpawnItem MW_MilitaryChest 1
```
Файл R46 побайтно совпадает с проверенным R46_TEST, изменено только имя PAK.
Проверены 93 лабораторных сценария UE4.27 и кормление яблоком по сети.
Это подтверждение кормления, а не повторная приёмка всех модов комплекта.

Для ручной загрузки используйте Git LFS: Source code ZIP может содержать
указатели вместо PAK. Официальные PAK/SIG, конфиги и Saved не заменять.
На работающих серверах старые PAK сохранены; новый R46 перекрывает кормление
при следующем запуске. Откат — убрать R46 при остановленной игре/сервере,
вернуть R42 в клиентский манифест и синхронизировать обе стороны.
