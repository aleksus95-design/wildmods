# MIDWAY / Wildmods — SCUM 1.3.6.1

MIDWAY / Wildmods — полный комплект для SCUM 1.3.6.1 (build 26621909).

Клиент: 153 PAK. Это обновление включает разработки с локального клиента и тестового сервера: новый истребитель, тепловизоры, камеры, Raptor, жилой прицеп, питомца-волка R7 и остальные действующие исправления.

Реестр обновлён из нового официального каталога. Сетевые компоненты транспорта приведены к текущим типам игры. PvE/PvP сохраняют свои настройки команд и спавна роботов. Полностью перекрытые старые PAK, временная диагностика и чужие тестовые моды исключены; игровые сохранения не удаляются.

При ручной установке закройте SCUM и перенесите прежнюю папку модов за пределы SCUM/Content/Paks, затем скопируйте новый полный комплект. Официальные PAK и SIG не трогайте. Не совмещайте разные FULL-комплекты. Через лаунчер дождитесь завершения синхронизации перед входом.

Границы проверки: целостность, зависимости, соответствие клиентских/серверных ресурсов и новая совместимость проверены отдельно. Старый дефект загрузки кровати/сидений прицепа в мультиплеере ещё не считается устранённым. Повторная охота, реакция противников и звук питомца R7 требуют игрового подтверждения. Разработчики SCUM также оставили известную проблему подбрасывания транспорта при отдельных столкновениях.
