# MIDWAY / Wildmods — SCUM1.3.6.1

MIDWAY — отдельные группы модового транспорта, R3 / 1863, 14.11.2026

Skyline, КамАЗ, ЗИЛ, танк и Ford Raptor переведены из VehicleSpawnGroup.Rager
в отдельные группы MIDWAY. Эти пять групп добавлены в список исключений
менеджера транспорта из лимитов серверных настроек. Штатный лимит Rager
не повышается. Другие типы транспорта этим патчем не меняются.

По поручению владельца серверный вариант загружен на PvE23629 и PvP23297
для применения при следующем обычном рестарте. Принудительного рестарта нет.
Клиентский и серверный варианты разные: в этом архиве ТОЛЬКО клиентский.
Лаунчер синхронизирует полный актуальный набор из156 PAK. Закройте SCUM
перед обновлением, входите после штатного рестарта нужного сервера.

Проверено совпадение исходных ресурсов с актуальными комплектами обоих
серверов и Wildmods. У машин меняется только SpawnGroup; у менеджера —
список исключений. Функции, таймеры, GUID, EntitySetup и AssetRegistry
сохранены. Сетевой фикс1862 и команды волка1809 остаются в комплекте.
Шифрованные официальные ресурсы, плагины и мировые базы не распространяются.

Тот же серверный PAK запускался на TEST23694 без fatal/assert и ошибок новых
тегов. Фактическое освобождение счётчика Rager, покупки при заполненном лимите
и сохранность после повторного рестарта ещё не проверены в игре.
Особенно требует проверки доступность модовых машин у штатного механика.
Публикация по поручению владельца не означает завершённого игрового теста.

Ручная установка: поверх полного комплекта12.11.2026 и патчей1862/1809
распаковать папку SCUM в корень игры. Этот архив — дополнительный патч,
не полный клиент. Официальные PAK/SIG не заменять.
