# WildMods / MIDWAY R79 + рулетка R6H18

WildMods / MIDWAY: **R79 + рулетка R6H18**, SCUM build 26320533.

Полный клиент: **99 PAK**. Удалены 8 полностью перекрытых пакетов; все действующие ресурсы сохранены побайтово.

- Рулетка R6H18: покупка 40 фишек за 1 млн, немедленное списание, общий раунд, баланс и результат в панели; исправления начислений и сохранения журнала операций.
- R77: привязка мишени дартса. R78: отключены старые рецепты WK за монеты. R79: исправлены данные камеры Спартанца и пассажирских камер Вертолёта2.
- Два серверных профиля PvE/PvP: FULL по 97 PAK, PATCH по 21 PAK. Индивидуальные отличия профилей сохранены.

Клиент и сервер должны обновляться согласованно. Скачивание архива не переключает серверы автоматически. Не устанавливайте серверный архив в игру клиента. Инструкция и SHA256 приложены.

Проверены хеши, архивы, равенство эффективных ресурсов после очистки, реестр и сетевые поля. Ограниченная проверка рулетки на TEST пройдена; игровые проверки R77/R78/R79 и двух реальных клиентов одновременно ещё не подтверждены. Сбой занятого водительского места ЗИЛа и исторические heartbeat-разрывы не объявляются исправленными.
