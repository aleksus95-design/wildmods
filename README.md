# MIDWAY — моды для лаунчера

M13 + Tank R95 + Coins R9 · SCUM build 25804202 · 32 PAK.
Общий клиентский комплект для PvP и PvE.

Coins R9 разрешает выдачу MW Coin через систему добычи игры.
MW Coin добавлена в таблицу разрешённых предметов новой системы добычи.
Все прежние записи таблицы, свойства монеты и каталог предметов сохранены.
Награда робота NPC — 1 монета после полного обыска нового тела.
Награда Silver — 1 монета и коробка .50 BMG после обыска.
Старые уже обысканные тела проверять повторно не нужно.

Закройте SCUM, перезапустите лаунчер, нажмите «УДАЛИТЬ МОДЫ»
и установите актуальный комплект. Официальные файлы игры сохраняются.

Coins R9 является дополнением к полному набору; CopperCoins R6 и LootCoins R1
по-прежнему нужны. Тестовые Coins R7/R8 и экспериментальный RobotCoins R2 не нужны.
Танк R95, панель M13, цены и прочие моды сохранены.

Проверки: целостность PAK, неизменность сетевых имён предметов и загрузка мира.
Итоговый тест появления монеты в теле робота после убийства требуется в игре.

INSTALL_MANIFEST.json содержит точный состав. VERIFY_FILES.cmd проверяет файлы.
Предыдущий комплект и история сохранены для отката.
