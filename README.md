MIDWAY R17 — SCUM 1.3.5.1.172191+172352, build 26280172

КЛИЕНТ: 65 PAK, основной репозиторий wildmods и лаунчер.
СЕРВЕР: отдельный полный архив, 67 PAK. Не ставить серверную версию игрокам.
HOTFIX: один общий PAK поверх полного R16 клиента И сервера.
Папки MIDWAY_R16 (базовые PAK) и MIDWAY_R17 (дополнение) нужны обе.

R17 исправляет сдвиг 899 штатных фабрик: чистый клиент перестаёт декодировать
контейнер Volkswagen как рубашку. Вместимость контейнера не изменялась.
2888 штатных фабрик и 9638 штатных PrimaryAsset IDs проверены без сдвигов.
10609 прежних модифицированных PrimaryAsset IDs, поля и RPC сохранены.

ОБНОВЛЕНИЕ КЛИЕНТА
Полностью закрыть SCUM, перезапустить лаунчер и обновить моды.
Если старый набор сохраняется — удалить моды через лаунчер и установить заново.
Для ручной установки нужен Git LFS; Source code ZIP может содержать указатели.
Папки MIDWAY_R16 и MIDWAY_R17 из клиентского репозитория скопировать в
SCUM/Content/Paks/~mods. Официальные PAK/SIG не трогать.
VERIFY_FILES.cmd проверяет состав и SHA-256; требуется Python 3.

ПЕРЕХОД СЕРВЕРА С R16
Остановить сервер. Сохранить СВЕЖУЮ копию SCUM.db и файлов -wal/-shm,
если они есть, из SCUM/Saved/SaveFiles. Нельзя использовать старую копию мира.
Из-за изменения физического имени сохранённые радиомашинки требуют переноса
RC_Car_ES -> яяРадиомашинка_Схема. CoreRedirect этот шаг не заменяет.
На отдельной офлайн-копии запустить:
python PREPARE_RC_SAVE_R17.py --input backup/SCUM.db --output ready/SCUM.db
Скрипт создаёт НОВУЮ базу, проверяет все таблицы и не устанавливает её.
Если отчёт показывает изменения, сохранить прежние DB/WAL/SHM вне SaveFiles
и установить подготовленную SCUM.db без прежних WAL/SHM. При нуле изменений
базу заменять не требуется. Другие данные и настройки сохранить.
Скопировать SCUM из полного SERVER-архива в /Server или, для полного R16,
добавить HOTFIX в /Server/SCUM/Content/Paks/~Mods/MIDWAY_R17.
Обновить модифицированные клиенты до R17, затем запустить сервер.
Не подключать клиент R16 к серверу R17 или наоборот.

ПОСЛЕ ОБНОВЛЕНИЯ
Проверить чистым клиентом штатные предметы и багажник Volkswagen.
Клиентом R17 проверить существующую и новую радиомашинку, F9/V, транспорт.
Файлы и реестры проверены в UE4.27; все игровые сценарии этим не покрываются.

ОТКАТ

не восстанавливать старый мир с потерей нового прогресса.
